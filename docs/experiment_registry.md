# Experiment Registry

Tracks completed experiment runs. Each entry links to its artifact directory
and summarizes the configuration. Metrics are populated once the run executes
against real data.

---

## Iteration 0 — Baseline Comparison

**Goal:** Establish four baseline configurations using the rules-first +
BioBERT-fallback infrastructure. No model training — BioBERT head is randomly
initialized. Results here confirm the pipeline plumbing works; meaningful
metrics require a fine-tuned checkpoint.

| Stage | Config | Artifact Dir |
| --- | --- | --- |
| `rules_only` | Rules classifier, abstentions zero-filled | `experiments/baseline_rules/` |
| `biobert_only` | Untrained BioBERT, threshold=0.5 | `experiments/baseline_biobert/` |
| `rules_then_biobert_default` | Rules-first, BioBERT fallback, threshold=0.5 | `experiments/baseline_rules_then_biobert/` |
| `rules_then_biobert_tuned` | Rules-first, BioBERT fallback, per-label tuned thresholds | `experiments/baseline_rules_then_biobert_tuned/` |

**Stage comparison report:** `experiments/stage_comparison_v1.md`
(generated by `src/ods_phenocontext/stage_compare.py` once real runs complete)

**Key notes:**
- Baseline 4 val metrics are optimistically biased (tuned and evaluated on same
  val set). See `docs/decision_log.md` for the full caveat.
- Confirmed class capped at 15,000 instances to address class imbalance.
  See `docs/decision_log.md`.
- All four stages share the same val split defined by the split manifest.
